# 聊天页 UI 规格（照截图 1:1 复刻）

本文是 `ChatScreen` 的**可照抄规格**：每个元素在默认态、点击态、面板态下长什么样，用什么颜色和尺寸，行为是什么。
右边一列写的是它在代码里的落点，改的时候按行号对照。

截图：1080×2400，Android 微信式私聊/群聊页。

---

## 1. 谁来发：怎么分清「我的」和「不是我的」

判定只有一条，`mine = message.sender == owner`（`ChatScreen.kt` 里 `ChatBubble(...)` 的调用处），`owner` 是这台设备的身份号。

| 元素 | 我的（mine = true） | 对方的（mine = false） |
|---|---|---|
| 水平位置 | 靠右 `Arrangement.End` | 靠左 `Arrangement.Start` |
| 头像 | **右侧**，气泡之后，间隔 8dp，32dp 圆 | 私聊：**不画头像**；群聊：左侧画（可点进主页） |
| 昵称 | 不画 | 只有群聊画，气泡上方 9sp 灰字 |
| 文字气泡 | 主色底 `#007AFF`、白字 | 灰底 `surfaceVariant`、深色字 |
| 时间戳 | 气泡内右下 8sp，白字 70% 透明 | 气泡内右下 8sp，灰字 `outline` |
| 图片/卡片 | 不套气泡底色，直接一张带圆角的卡 | 同左，只是靠左 |

> 群聊里对方头像**保留**：那是「点这个人进主页」的唯一入口。私聊里对方不画，是因为页面标题已经写了他是谁。

## 2. 头像

- 尺寸 32dp 圆，底色 `primary` 15% 透明，中间一个字（名字首字）。
- 自己那颗用 `userName`（调用方传进来的设备显示名）首字，空就是「我」。
- 后端**没有**头像 URL 字段（`ChatMessage` 里没有 avatar 之类），所以现在是首字兜底。将来要真图，加一列 storage 路径 + `ChatRowAvatar(objectPath = ...)` 分支即可，别的不用动。
- 点自己的头像不挂任何动作。

## 3. 气泡

| 项 | 值 |
|---|---|
| 圆角 | 14dp |
| 最大宽 | 260dp |
| 内边距 | 水平 12dp / 垂直 8dp |
| 字号 / 行高 | 14sp / 19sp |
| 自己的底色 / 字色 | `MaterialTheme.primary`（默认 `#007AFF`）/ `onPrimary`（白） |
| 对方的底色 / 字色 | `surfaceVariant` / `onSurfaceVariant` |
| 长按 | 弹菜单：复制 / 回复 / 转发 /（自己的）撤回 /（自己的）删除 |

## 4. 时间戳

- **居中灰字**（`ChatDayDivider`）：换天时出现，格式 `yyyy-MM-dd HH:mm`；同一天里两条消息隔了 **≥ 5 分钟**，再起一条，只写 `HH:mm`。
- **气泡内小字**：每条都带 `HH:mm`，8sp。

## 5. 图片 / 分享卡片

- 图片消息：不套气泡，圆角 12dp，最大 220×280dp；点击进全屏查看器。
- 全屏查看器（`ChatImageViewer`）：黑底、单指双击 1×↔2.5×、双指捏合 1×–4×、拖动位移、点任意处或右上 × 关闭。
- 分享卡片：圆角 12dp，最宽 220dp，自己发的加一层 10% 主色底。
- 视频消息和「来自视频 / 话题」那套卡片**后端还没有字段**，现在没有对应类型（见第 9 节）。

## 6. 输入栏

整条栏：浅灰底 `#F7F7F7`，水平 10dp / 垂直 6dp，无分隔线。

从左到右：四宫格（更多）→（群聊时）@ → 输入框 → 语音 **或** 发送 → 表情 → 加号。

| 元素 | 值 |
|---|---|
| 输入框 | 40dp 起，最高 120dp（约 5 行，超过自己滚）；圆角 10dp；底色 `#F2F2F2`；无边框；内边距 12dp / 9dp；字号 14sp |
| 输入框光标 | 粉色 `#FE2C55` |
| 占位文字 | 灰色 `#999999`，14sp，**三态**见下 |
| 语音 / 发送 | 同一个位置二选一：草稿空 → 语音图标（36dp，无底）；草稿非空 → 粉色「发送」胶囊 |
| 表情 | 笑脸 36dp，抽屉式拉开表情面板 |
| 加号 | `addCircle` 36dp，拉开「更多」面板 |

### 占位文字三态

| 状态 | 文案 |
|---|---|
| 面板打开（表情 / 更多 / @） | `发消息` |
| 键盘弹出、输入框有焦点 | `发消息或按住说话...` |
| 都没开 | `发消息` |

### 点击态

- 点输入框：拿焦点、弹输入法、**三个面板自动收起**（面板 + 键盘不允许同时占两半屏）。
- 点输入栏其他钮：开对应面板前先 `clearFocus()` + 收输入法。
- 焦点本身不改变输入框外观（不换底色、不加边框），只有光标出现。

## 7. 输入法（键盘）在哪儿

- 位置：屏幕**下沿**弹起，输入栏整体被顶到键盘上方，消息区压缩。
- Android 侧 `windowSoftInputMode="adjustResize"`；但 Activity 开了 `enableEdgeToEdge()`，这时系统**不再缩窗口**，必须由 Compose 读 inset：`Column(...).imePadding().navigationBarsPadding()`。
- 没有这一行时现象是：键盘直接盖住输入栏，看起来像「按钮点了没反应」。这是曾经的真实 bug。

## 8. 表情面板

高度 300dp（约占屏幕 45%），底色 `surfaceContainerLow`，贴在输入栏正上方。

从上到下：

1. **最近使用** + 右侧「装扮 >」，一行 **8 格**，不横向滚动（不满 8 格用空格占位，避免前几颗被拉大）。
2. **全部表情**，8 列网格，格子 40dp / 图 30dp，间距 2dp。
3. 网格**右下角浮动两个钮**（压在网格上，网格底部留 56dp 给它们让位）：
   - 浅灰圆 30dp，中间 ×：删掉草稿里最后一**整颗**表情 token（不是半个 `[偷`）。
   - 粉色胶囊「发送」：底色 `#FE2C55`，白字 13sp，禁用时降到 40% 透明。

### 点一颗表情到底发生什么

**不会立即发出去。** 点一颗 = 把它对应的 token（如 `[偷笑]`）插进草稿，输入框里那一格画成表情图；要发就按右下角「发送」，或按输入栏那颗发送。
好处：能一口气挑好几颗、还能配文字；也避免手滑发错。

发出去的消息，正文里是 token 字符串，本客户端渲染成图片；不认这套 token 的客户端会看到 `[偷笑]` 字面量（不会崩，也不会丢字）。

## 9. 发送键

| 位置 | 颜色 | 形状 | 状态 |
|---|---|---|---|
| 输入栏（草稿非空时） | `#FE2C55` | 胶囊，白字 13sp，内边距 14×7dp | 发送中降到 40% 透明且不可点 |
| 表情面板右下角 | `#FE2C55` | 同上，内边距 20×7dp | 草稿空 / 发送中同样降透明 |

两条走的是**同一个** `send()`：引用、@ 名单、失败重发的语义只有一处。

## 10. 快捷短语胶囊

只在「没有面板 且 草稿为空」时出现在输入栏上方一行（面板一拉开就收起来，不然会挤在面板和输入栏之间）。
胶囊：`surfaceContainerHigh` 底、`percent = 50` 圆角、10×5dp 内边距、`caption2` 灰字。
点一下只插入文字，emoji 头图不发出去。

## 11. 还没做（等后端字段）

| 想做 | 缺什么 |
|---|---|
| 真头像（现在是首字） | `ChatMessage` 没有头像 storage 路径字段 |
| 视频消息（竖缩略图 + 播放三角 + 左下表情角标） | 没有 `kind = "video"`、没有 mp4 字段 |
| 「分享 @某人 的评论 / 来自视频 / #话题」卡片 | `ShareCard` 只有 kind/target/title/note |
| 消息里的红包 / 语音条 | 后端没有对应 kind |
