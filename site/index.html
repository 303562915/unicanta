安装

  1. 安装 Shizuku 并按其引导启动（Android 16 及以上建议用 fork 版）。
  2. 下载上面的 APK 并安装。若被拦截，在系统设置中允许「安装未知应用」。
  3. 打开 Canta，在顶部授权 Shizuku，之后即可浏览、停用或卸载任意应用。

常见问题

为什么下载链接不在 GitHub Releases 里？

源码仓库是私有的，私有仓库的 Release 资产对外部访问会返回 404。这里托管的是构建产物的公开镜像，与源码仓库的 CI 自动同步。

APK 是怎么构建的？可信吗？

由 GitHub Actions 在云端从私有仓库的 tag 构建、签名并上传，本页面与 APK 由同一次流水线一起发布。你可以用上面的 SHA-256 与自己下载到的文件比对。

会分发到应用商店吗？

不会。只从这里和源码仓库发布。请只从本页面下载，第三方转载的包无法保证未被改动。

支持哪些 Android 版本？

最低 Android 8.0。核心功能依赖 Shizuku 提供的 shell 权限，无需 root，也无需解锁 Bootloader。

卸载关键系统应用会导致 bootloop，只能恢复出厂设置。使用风险自负。
